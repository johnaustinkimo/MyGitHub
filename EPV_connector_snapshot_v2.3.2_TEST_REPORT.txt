Portability changes
-------------------
- OpenSSL 1.0.2/1.1/3.x server-method compatibility
- Legacy TLS floor enforcement for RHEL7/OpenSSL 1.0.2
- Legacy/new X509 notBefore/notAfter accessor compatibility
- Certificate expiry check reads PEM directly (avoids newer SSL_CTX getter dependency)
- Salted SHA-256 password verifier changed to one-shot EVP_Digest(), available on OpenSSL 1.0.2+
- Adaptive _FORTIFY_SOURCE (2 on older glibc, 3 on newer glibc)
- Compiler flag probing for older GCC
- Stack protector fallback
- Optional -latomic detection
- Dynamic shutdown status uses EPV_VERSION

Important
---------
Build RHEL7 production binaries on RHEL7 (or against a RHEL7-compatible sysroot).
Do not assume a binary linked on RHEL9/RHEL10 will run on glibc 2.17.
--debug intentionally exposes sensitive credentials/tokens and should normally be disabled in production.
